# The Last Augustus

A total conversion mod for Imperator: Rome that brings the game into the early Middle Ages!  
The mod starts in **527 AD**, marking the crowning of **Justinian I** and the breakup of **Clovis' Frankish Kingdom**.  
Navigate the transition from **Antiquity to the Middle Ages**, shaping the fate of crumbling empires and rising new kingdoms.  

## 👤 Original Developer  
**Tjrolex**  

## 🏛 Major Features  

- **A New Timeline (527 AD)**  
- **Overhauled Map & Nations**  
- **Religion System Expansion**  
- **Expanded bloodlines for ruling families**  

## 🌍 Mission Trees  
- ☠️ One broken one for **Rome**  

## 📜 Content  
- One working event for **Londinium**  

## 🛠 Troubleshooting  

If the mod crashes, go to the Imperator folder and delete everything except the **save games** and **mod** folders.  
📂 Location: `Documents\Paradox Interactive\Imperator`  

## ✅ Compatibility
